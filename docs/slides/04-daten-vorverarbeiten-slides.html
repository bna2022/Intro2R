Tidyverse und Tidy Data

Was ist das Tidyverse?

Das tidyverse ist eine Sammlung von R-Paketen für typische Schritte der Datenanalyse.

Aufgabe Paket Beispiele
Daten transformieren dplyr filter(), select(), mutate()
Daten umformen tidyr pivot_wider(), pivot_longer()
Texte bearbeiten stringr str_trim(), str_detect()
Daten visualisieren ggplot2 ggplot()

Die Pakete verwenden eine ähnliche Schreibweise und lassen sich gut kombinieren.

Tidy Data

Eine Tabelle ist tidy, wenn sie drei Grundregeln erfüllt:

  1. Jede Variable steht in einer eigenen Spalte.
  2. Jede Beobachtung steht in einer eigenen Zeile.
  3. Jeder Wert steht in einer eigenen Zelle.

Beispiel: Eine Zeile in gapminder beschreibt ein Land in einem bestimmten Jahr.

Vorbereitung

Pakete laden

# Nur einmal nötig:
# install.packages("tidyverse")
# install.packages("gapminder")

# In jeder neuen Sitzung nötig:
library(tidyverse)
library(gapminder)

Note

Wenn eine Funktion in mehreren Paketen vorkommt, kann der Paketname vorangestellt werden, zum Beispiel dplyr::filter().

Daten mit dplyr bearbeiten

Warum dplyr?

Mit Base R ist vieles möglich:

gapminder[gapminder$country == "Germany" & gapminder$year >= 1990,
          c("country", "year", "lifeExp", "gdpPercap")]
# A tibble: 4 × 4
  country  year lifeExp gdpPercap
  <fct>   <int>   <dbl>     <dbl>
1 Germany  1992    76.1    26505.
2 Germany  1997    77.3    27789.
3 Germany  2002    78.7    30036.
4 Germany  2007    79.4    32170.

Der Code funktioniert, aber mehrere Dinge stehen gleichzeitig in einem Ausdruck.

Mit dplyr werden Analyseschritte klarer getrennt.

Dieselbe Idee mit dplyr

gapminder |>
  filter(country == "Germany", year >= 1990) |>
  select(country, year, lifeExp, gdpPercap)
# A tibble: 4 × 4
  country  year lifeExp gdpPercap
  <fct>   <int>   <dbl>     <dbl>
1 Germany  1992    76.1    26505.
2 Germany  1997    77.3    27789.
3 Germany  2002    78.7    30036.
4 Germany  2007    79.4    32170.

Wichtige dplyr-Verben

Frage Funktion
Welche Zeilen brauche ich? filter()
Welche Spalten brauche ich? select()
Wie sortiere ich Daten? arrange()
Wie berechne ich neue Variablen? mutate()
Wie fasse ich Gruppen zusammen? group_by() + summarise()

dplyr ist keine neue Datenstruktur, sondern eine lesbare Sprache für Data Frames und Tibbles.

Zeilen auswählen

Zeilen filtern mit filter()

Mit filter() wählen Sie Zeilen aus, die eine Bedingung erfüllen.

gapminder |>
  filter(country == "Germany")

Zum Vergleich in Base R:

gapminder[gapminder$country == "Germany", ]

Mehrere Bedingungen

Mehrere Bedingungen innerhalb von filter() werden wie ein logisches UND behandelt.

gapminder |>
  filter(country == "Germany", year >= 1990)

Das ist gleichbedeutend mit:

gapminder |>
  filter(country == "Germany" & year >= 1990)

Mehrere mögliche Werte

Für mehrere mögliche Werte nutzen Sie %in%.

gapminder |>
  filter(country %in% c("Germany", "France", "Italy"))

Gelesen:

Behalte alle Zeilen, bei denen country in dieser Liste vorkommt.

Arbeitsschritte verbinden

Der Pipe-Operator |>

Der Pipe-Operator |> übergibt das Ergebnis eines Schrittes an den nächsten Schritt.

Man kann ihn als dann lesen.

gapminder |>
  filter(country == "Germany") |>
  select(year, lifeExp)

Tip

Lesen Sie den Code laut: Nimm gapminder, dann filtere Deutschland, dann wähle Jahr und Lebenserwartung.

Eine typische Analysekette

gapminder |>
  filter(continent == "Europe", year == 2007) |>
  select(country, lifeExp, gdpPercap) |>
  arrange(desc(lifeExp))

Dieser Code macht vier Dinge:

  1. Datensatz nehmen,
  2. auf Europa und 2007 filtern,
  3. drei Spalten auswählen,
  4. absteigend nach Lebenserwartung sortieren.

Übung: Pipe-Ketten lesen

Beschreiben Sie in eigenen Worten, was dieser Code macht:

gapminder |>
  filter(continent == "Asia", year == 2007) |>
  select(country, pop, lifeExp) |>

Gruppieren und zusammenfassen

Viele Fragen beziehen sich auf Gruppen:

  • Wie hoch ist die durchschnittliche Lebenserwartung pro Kontinent?
  • Wie groß ist die Bevölkerung pro Kontinent?
  • Welche Gruppe hat den höchsten Mittelwert?

Dafür kombinieren wir group_by() und summarise().

Durchschnitt pro Kontinent

gapminder |>
  filter(year == 2007) |>
  group_by(continent) |>
  summarise(mean_lifeExp = mean(lifeExp))
# A tibble: 5 × 2
  continent mean_lifeExp
  <fct>            <dbl>
1 Africa            54.8
2 Americas          73.6
3 Asia              70.7
4 Europe            77.6
5 Oceania           80.7

Dieser Code bedeutet: 1. Behalte nur das Jahr 2007. 2. Gruppiere nach Kontinent. 3. Berechne pro Kontinent die mittlere Lebenserwartung.

Mehrere Kennzahlen berechnen

gapminder |>
  filter(year == 2007) |>
  group_by(continent) |>
  summarise(
    mean_lifeExp = mean(lifeExp),
    min_lifeExp = min(lifeExp),
    max_lifeExp = max(lifeExp),
    n_countries = n()
  )
# A tibble: 5 × 5
  continent mean_lifeExp min_lifeExp max_lifeExp n_countries
  <fct>            <dbl>       <dbl>       <dbl>       <int>
1 Africa            54.8        39.6        76.4          52
2 Americas          73.6        60.9        80.7          25
3 Asia              70.7        43.8        82.6          33
4 Europe            77.6        71.8        81.8          30
5 Oceania           80.7        80.2        81.2           2

n() zählt, wie viele Zeilen in jeder Gruppe enthalten sind.

Daten umformen mit tidyr

Warum Daten umformen?

Manchmal liegen Daten nicht in der Form vor, die wir für eine Analyse brauchen.

Beispiele:

  • Messzeitpunkte stehen in mehreren Spalten.
  • Variablennamen stehen als Werte in einer Spalte.
  • Für Vergleiche sollen Werte nebeneinanderstehen.

tidyr hilft dabei, Daten in die passende Form zu bringen.

Ist dieser Datensatz tidy?

lebenserwartung_breit <- tibble(
  land = c("Deutschland", "Frankreich", "Italien"),
  `2000` = c(78.0, 79.1, 79.8),
  `2005` = c(79.2, 80.3, 81.0),
  `2010` = c(80.1, 81.6, 82.0)
)

pivot_wider(): die Argumente

pivot_wider(
  names_from = year,
  values_from = lifeExp
)
  • names_from = year: Werte aus year werden neue Spaltennamen.
  • values_from = lifeExp: Werte aus lifeExp werden eingetragen.

Das Ergebnis ist breiter: pro Land eine Zeile, pro Jahr eine Spalte.

gapminder_lang <- gapminder_breit |>

Textdaten bereinigen mit stringr

Warum Textdaten bereinigen?

Manchmal liegt das Problem nicht in der Tabellenstruktur, sondern in den Textwerten.

Typische Probleme:

  • zusätzliche Leerzeichen,
  • unterschiedliche Groß- und Kleinschreibung,
  • uneinheitliche Schreibweisen,
  • Werte, die nur teilweise gesucht oder ersetzt werden sollen.

Beispiel: uneinheitliche Ländernamen

laender_roh <- tibble(
  country = c(" Germany", "france", "ITALY ",
              "United  Kingdom", "bosnia and herzegovina"),
  year = c(2007, 2007, 2007, 2007, 2007),
  lifeExp = c(79.4, 80.7, 80.5, 79.4, 74.9)
)

laender_roh
# A tibble: 5 × 3
  country                   year lifeExp
  <chr>                    <dbl>   <dbl>
1 " Germany"                2007    79.4
2 "france"                  2007    80.7
3 "ITALY "                  2007    80.5
4 "United  Kingdom"         2007    79.4
5 "bosnia and herzegovina"  2007    74.9

Die Ländernamen sind absichtlich uneinheitlich geschrieben.

Leerzeichen bereinigen

laender_roh |>
  mutate(
    country_clean = country |>
      str_trim() |>
      str_squish()
  )
# A tibble: 5 × 4
  country                   year lifeExp country_clean         
  <chr>                    <dbl>   <dbl> <chr>                 
1 " Germany"                2007    79.4 Germany               
2 "france"                  2007    80.7 france                
3 "ITALY "                  2007    80.5 ITALY                 
4 "United  Kingdom"         2007    79.4 United Kingdom        
5 "bosnia and herzegovina"  2007    74.9 bosnia and herzegovina
  • str_trim() entfernt Leerzeichen außen.
  • str_squish() reduziert mehrere Leerzeichen innerhalb eines Textes.

Groß- und Kleinschreibung vereinheitlichen

laender_clean <- laender_roh |>
  mutate(
    country_clean = country |>
      str_trim() |>
      str_squish() |>
      str_to_title()
  )

laender_clean
# A tibble: 5 × 4
  country                   year lifeExp country_clean         
  <chr>                    <dbl>   <dbl> <chr>                 
1 " Germany"                2007    79.4 Germany               
2 "france"                  2007    80.7 France                
3 "ITALY "                  2007    80.5 Italy                 
4 "United  Kingdom"         2007    79.4 United Kingdom        
5 "bosnia and herzegovina"  2007    74.9 Bosnia And Herzegovina

str_to_title() bringt Text in eine einheitliche Schreibweise.

Textmuster suchen mit str_detect()

laender_clean |>
  mutate(
    contains_united = str_detect(country_clean, "United")
  )
# A tibble: 5 × 5
  country                   year lifeExp country_clean          contains_united
  <chr>                    <dbl>   <dbl> <chr>                  <lgl>          
1 " Germany"                2007    79.4 Germany                FALSE          
2 "france"                  2007    80.7 France                 FALSE          
3 "ITALY "                  2007    80.5 Italy                  FALSE          
4 "United  Kingdom"         2007    79.4 United Kingdom         TRUE           
5 "bosnia and herzegovina"  2007    74.9 Bosnia And Herzegovina FALSE

Das Ergebnis ist eine logische Spalte mit TRUE oder FALSE.

Textmuster suchen mit str_detect()

Direkt filtern:

laender_clean |>
  filter(str_detect(country_clean, "United"))
# A tibble: 1 × 4
  country          year lifeExp country_clean 
  <chr>           <dbl>   <dbl> <chr>         
1 United  Kingdom  2007    79.4 United Kingdom

Schreibweisen gezielt korrigieren

laender_clean <- laender_clean |>
  mutate(
    country_clean = case_when(
      str_detect(country_clean, "Bosnia") ~ "Bosnia and Herzegovina",
      TRUE ~ country_clean
    )
  )

laender_clean
# A tibble: 5 × 4
  country                   year lifeExp country_clean         
  <chr>                    <dbl>   <dbl> <chr>                 
1 " Germany"                2007    79.4 Germany               
2 "france"                  2007    80.7 France                
3 "ITALY "                  2007    80.5 Italy                 
4 "United  Kingdom"         2007    79.4 United Kingdom        
5 "bosnia and herzegovina"  2007    74.9 Bosnia and Herzegovina

TRUE ~ country_clean bedeutet: Wenn keine Bedingung zutrifft, bleibt der Wert erhalten.

Warum ist das wichtig?

R vergleicht Zeichenketten exakt.

"Germany" == " Germany"
[1] FALSE
"Germany" == "germany"
[1] FALSE
"United Kingdom" == "United  Kingdom"
[1] FALSE

Solche Unterschiede können dazu führen, dass Filter, Gruppierungen oder Joins nicht wie erwartet funktionieren.

Abschluss

Merke: stringr

Wichtige Funktionen:

str_trim(text)              # Leerzeichen außen entfernen
str_squish(text)            # Mehrfache Leerzeichen reduzieren
str_to_title(text)          # Groß-/Kleinschreibung vereinheitlichen
str_detect(text, "Muster")  # Textmuster erkennen

Zusammenfassung

In dieser Einheit haben Sie gelernt:

  • filter() behält Zeilen nach Bedingungen.
  • select() wählt Spalten aus oder schließt sie aus.
  • |> macht Analyseketten lesbarer.
  • arrange() sortiert Daten.
  • mutate() berechnet neue Variablen.
  • group_by() und summarise() berechnen gruppierte Kennzahlen.
  • pivot_wider() und pivot_longer() formen Daten um.
  • stringr bereinigt Textwerte.
