Warum Daten visualisieren?

Visualisierungen helfen bei zwei Aufgaben:

  1. Exploration
    Muster, Ausreißer, Gruppenunterschiede und Zusammenhänge erkennen.

  2. Kommunikation
    Eine Datenbotschaft klar, verständlich und ehrlich darstellen.

Typische Fragen an Daten

  • Wie ist eine Variable verteilt?
  • Gibt es Ausreißer?
  • Hängen zwei Variablen zusammen?
  • Unterscheiden sich Gruppen?
  • Gibt es nichtlineare Muster?
  • Gibt es Strukturen, die in Tabellen schwer erkennbar sind?

Base R

Base R: schnelle Explorationsgrafiken

Base R enthält bereits viele Grafikfunktionen.

Vorteile:

  • direkt verfügbar,
  • schnell für erste explorative Analysen,
  • gut für einfache Standardgrafiken.

Grenze:

  • komplexere Grafiken werden schnell schwer lesbar im Code.

Base R: Histogramm

Ein Histogramm zeigt die Verteilung einer metrischen Variable.

hist(Pima.tr$glu,
     breaks = 20,
     main = "Verteilung der Glukosewerte",
     xlab = "Glukosewert",
     ylab = "Häufigkeit")

Base R: Boxplot

Ein Boxplot zeigt Median, Quartile und mögliche Ausreißer.

boxplot(glu ~ type,
        data = Pima.tr,
        main = "Glukosewerte nach Diabetes-Status",
        xlab = "Diabetes-Status",
        ylab = "Glukosewert")

Base R: Streudiagramm

Ein Streudiagramm zeigt den Zusammenhang zwischen zwei metrischen Variablen.

plot(Pima.tr$bmi, Pima.tr$glu,
     main = "Zusammenhang zwischen BMI und Glukosewert",
     xlab = "BMI",
     ylab = "Glukosewert",
     pch = 19)

Base R: Gruppen farblich markieren

plot(Pima.tr$bmi, Pima.tr$glu,
     main = "BMI und Glukosewert nach Diabetes-Status",
     xlab = "BMI",
     ylab = "Glukosewert",
     pch = 19,
     col = ifelse(Pima.tr$type == "Yes", "red", "blue"))

legend("topleft",
       legend = c("Diabetes: Yes", "Diabetes: No"),
       col = c("red", "blue"),
       pch = 19)

Base R: Dichteplot

Ein Dichteplot ist eine geglättete Alternative zum Histogramm.

plot(density(Pima.tr$glu),
     main = "Dichte der Glukosewerte",
     xlab = "Glukosewert")

ggplot2

Von Base R zu ggplot2

Base R beschreibt häufig, wie etwas gezeichnet wird.

ggplot2 beschreibt stärker, welche Variablen wie dargestellt werden.

Grundidee:

Eine Grafik wird aus Bausteinen zusammengesetzt.

ggplot2 laden

library(ggplot2)

Ein einfaches Streudiagramm:

ggplot(Pima.tr, aes(x = age, y = glu)) +
  geom_point()

Grammar of Graphics

Eine Grafik besteht aus mehreren Komponenten:

Komponente Bedeutung
Daten Datensatz
Ästhetiken Zuordnung von Variablen zu visuellen Eigenschaften
Geometrien Punkte, Linien, Balken, Boxplots …
Skalen Achsen, Farben, Größen
Facetten Teilgrafiken nach Gruppen
Theme Gestaltung der Grafik

Grundform von ggplot2

ggplot(data = DATENSATZ,
       aes(x = VARIABLE1, y = VARIABLE2)) +
  geom_...()

Grundform von ggplot2

Beispiel:

ggplot(data = Pima.tr,
       aes(x = age, y = glu)) +
  geom_point()

Ästhetiken: aes()

aes() legt fest, welche Variable auf welche visuelle Eigenschaft abgebildet wird.

p <- ggplot(Pima.tr, aes(x = age, y = glu, color = type)) +
  geom_point(size = 2)

Ergebnis

Innerhalb oder außerhalb von aes()?

Variable Farbe nach Gruppe:

ggplot(Pima.tr, aes(x = age, y = glu, color = type)) +
  geom_point()

Konstante Farbe für alle Punkte:

ggplot(Pima.tr, aes(x = age, y = glu)) +
  geom_point(color = "steelblue")

Geometrien: Darstellungsform wählen

Ziel Geometrie
Zusammenhang zweier metrischer Variablen geom_point()
Verlauf über eine geordnete Variable geom_line()
Verteilung einer Variable geom_histogram()
geglättete Verteilung geom_density()
Gruppenvergleich metrischer Werte geom_boxplot()
Häufigkeiten geom_bar()
bereits aggregierte Werte geom_col()

Punktdiagramm

ggplot(Pima.tr, aes(x = bmi, y = glu)) +
  geom_point()

Interpretation: Jeder Punkt steht für eine Person.

Histogramm mit ggplot2

ggplot(Pima.tr, aes(x = glu)) +
  geom_histogram(bins = 20)

Histogramm mit ggplot2

bins legt fest, in wie viele Klassen die Werte eingeteilt werden.

Boxplot mit ggplot2

ggplot(Pima.tr, aes(x = type, y = glu)) +

Layer: Grafiken schrittweise aufbauen

ggplot(Pima.tr, aes(x = bmi, y = glu)) +

  geom_smooth(method = "lm", se = FALSE)

Layer: Grafiken schrittweise aufbauen

Achsen und Transformationen

Manchmal sind transformierte Achsen besser lesbar.

ggplot(Pima.tr, aes(x = age, y = glu)) +
  geom_point() +
  scale_y_continuous(
  name = "Glukosewert",
  limits = c(0, 250),
  breaks = seq(0, 250, 50)
) +
  scale_x_continuous(name = "Alter")

scale_y_continuous() passt die y-Achse für numerische Werte an, zum Beispiel die Beschriftung, den Wertebereich oder die Achsenmarkierungen.

Achsen und Transformationen

Gruppierung mit Farbe

ggplot(Pima.tr, aes(x = bmi, y = glu, color = type)) +

Faceting

Facetten teilen eine Grafik in mehrere Teilgrafiken auf.

ggplot(Pima.tr, aes(x = bmi, y = glu)) +
  geom_point() +
  facet_wrap(~ type)

Gut geeignet, wenn Gruppen getrennt betrachtet werden sollen.

Beschriftungen und Titel

ggplot(Pima.tr, aes(x = bmi, y = glu, color = type)) +
  geom_point(size = 3, alpha = 0.8) +
  labs(
    title = "Zusammenhang zwischen BMI und Glukosewert",
    subtitle = "Pima.tr-Datensatz",
    x = "Body-Mass-Index",
    y = "Glukosewert",
    color = "Diabetesstatus"
  )

Beschriftungen und Titel

Themes

Themes verändern das Erscheinungsbild einer Grafik.

ggplot(Pima.tr, aes(x = bmi, y = glu, color = type)) +
  geom_point(size = 3, alpha = 0.8) +
  theme_minimal()

Wichtige Themes in ggplot2

Beispiele:

  • theme_minimal() → schlicht und modern
  • theme_classic() → klassische Achsen ohne Hintergrundgitter
  • theme_bw() → weißer Hintergrund mit Gitternetz
  • theme_light() → helles, dezentes Theme
  • theme_void() → fast keine Achsen oder Beschriftungen

Wichtig: Themes verändern nur das Aussehen, nicht die Daten.

Eine Grafik schrittweise verbessern

ggplot(Pima.tr, aes(x = bmi, y = glu)) +

Schrittweise verbessern: Farbe und Transparenz

Finale Version

ggplot(Pima.tr, aes(x = bmi, y = glu, color = type)) +
  geom_point(size = 3, alpha = 0.7) +
  facet_wrap(~ type) +

    y = "Glukosewert",
    color = "Diabetesstatus"

Was macht eine gute Grafik aus?

Tip

Eine gute Grafik sollte nicht überladen sein. Jedes zusätzliche Element sollte eine Funktion haben.

Sinnvolle Verbesserungen sind zum Beispiel: - aussagekräftige Achsenbeschriftungen, - erklärender Titel, - verständliche Legende, - passende Farben, - Transparenz bei vielen Punkten, - Facetten für Gruppenvergleiche, - zurückhaltendes Theme.

ggplot2 Fehler

Typische Fehler bei ggplot2

Fehler 1: + vergessen

ggplot(Pima.tr, aes(x = age, y = glu))
  geom_point()

Richtig:

ggplot(Pima.tr, aes(x = age, y = glu)) +
  geom_point()

Typische Fehler: aes() falsch verwenden

Variable innerhalb von aes():

ggplot(Pima.tr, aes(x = age, y = glu, color = type)) +
  geom_point()

Konstante außerhalb von aes():

ggplot(Pima.tr, aes(x = age, y = glu)) +
  geom_point(color = "blue")

Typische Fehler: geom_bar() vs. geom_col()

# zählt Beobachtungen pro Gruppe
ggplot(Pima.tr, aes(x = type)) +
  geom_bar()

# nutzt vorhandene y-Werte
ggplot(mittelwerte, aes(x = type, y = glu)) +
  geom_col()

Grafiken speichern

p <- ggplot(Pima.tr, aes(x = bmi, y = glu, color = type)) +
  geom_point() +
  theme_minimal()

ggsave("pima_bmi_glukose.png", plot = p,
       width = 8, height = 5, dpi = 300)

Note

Für Abgaben oder Berichte sollten Grafiken reproduzierbar gespeichert werden.

Netzwerkvisualisierung

Netzwerkvisualisierung

Netzwerke bestehen aus:

  • Knoten: Objekte, Personen, Webseiten, Stationen
  • Kanten: Beziehungen zwischen diesen Knoten

Beispiel:

Wer kennt wen?

Beispiel: Kleines Netzwerk

library(igraph)

kanten <- data.frame(
  von = c("Anna", "Anna", "Ben", "Clara", "David", "Eva"),
  zu  = c("Ben", "Clara", "David", "David", "Eva", "Anna")
)

kanten
    von    zu
1  Anna   Ben
2  Anna Clara
3   Ben David
4 Clara David
5 David   Eva
6   Eva  Anna

Netzwerkobjekt erstellen

netz <- graph_from_data_frame(
  d = kanten,
  directed = FALSE
)

netz
IGRAPH 63fe524 UN-- 5 6 -- 
+ attr: name (v/c)
+ edges from 63fe524 (vertex names):
[1] Anna --Ben   Anna --Clara Ben  --David Clara--David David--Eva  
[6] Anna --Eva

graph_from_data_frame() erzeugt aus einer Kantenliste ein Netzwerkobjekt.

Zwei Darstellungen desselben Netzwerks

Ein Netzwerk kann unterschiedlich gespeichert werden:

Darstellung Idee
Kantenliste Jede Zeile beschreibt eine Verbindung
Adjazenzmatrix Zeilen und Spalten sind Knoten
Visualisierung Knoten und Kanten werden gezeichnet

Die Datenstruktur und die Grafik sind nicht dasselbe.

Adjazenzmatrix

Eine Adjazenzmatrix zeigt, welche Knoten miteinander verbunden sind.

as_adjacency_matrix(netz, sparse = FALSE)
      Anna Ben Clara David Eva
Anna     0   1     1     0   1
Ben      1   0     0     1   0
Clara    1   0     0     1   0
David    0   1     1     0   1
Eva      1   0     0     1   0

Interpretation:

  • 1 bedeutet: Es gibt eine Verbindung.
  • 0 bedeutet: Es gibt keine Verbindung.
  • Zeilen und Spalten stehen für dieselben Knoten.

Netzwerk visualisieren

plot(netz)

Die Grafik zeigt dieselben Informationen wie die Adjazenzmatrix, aber visuell.

Die Adjazenzmatrix ist gut für Berechnungen.
Die Netzwerkvisualisierung ist gut für Muster und Strukturen.

Netzwerk schöner darstellen

plot(
  netz,
  vertex.color = "lightblue",
  vertex.size = 30,
  vertex.label.cex = 1.1,
  edge.width = 2
)

Wichtige Argumente:

  • vertex.color: Farbe der Knoten
  • vertex.size: Größe der Knoten
  • vertex.label.cex: Größe der Beschriftung
  • edge.width: Dicke der Kanten

Zentrale Knoten erkennen

Ein einfacher Zentralitätswert ist der Grad.

grad <- degree(netz)

grad
 Anna   Ben Clara David   Eva 
    3     2     2     3     2

Der Grad zählt, wie viele Verbindungen ein Knoten hat.

Zentrale Knoten hervorheben

plot(
  netz,
  vertex.size = grad * 8,
  vertex.color = "lightblue",
  vertex.label.cex = 1.1,
  edge.width = 2
)

Größere Knoten haben mehr Verbindungen.

Layouts verändern

Das Layout bestimmt, wo die Knoten gezeichnet werden.

plot(
  netz,
  layout = layout_with_fr(netz),
  vertex.size = grad * 8,
  vertex.color = "lightblue",
  edge.width = 2
)

layout_with_fr() versucht, verbundene Knoten näher zusammen zu platzieren.

Wann sind Netzwerkvisualisierungen sinnvoll?

Netzwerkvisualisierungen helfen, wenn Beziehungen im Mittelpunkt stehen.

Beispiele:

  • soziale Netzwerke
  • Webseiten und Links
  • Verkehrsnetze
  • Kommunikationsnetzwerke
  • gemeinsame Auftreten von Begriffen

Nicht einzelne Variablen stehen im Vordergrund, sondern Beziehungen.

Grenzen von Netzwerkvisualisierungen

Netzwerke können schnell unübersichtlich werden.

Problematisch sind:

  • sehr viele Knoten
  • sehr viele Kanten
  • überlappende Beschriftungen
  • Layouts, die unterschiedlich aussehen können

Bei großen Netzwerken sind Kennzahlen oft wichtiger als die reine Grafik.
